# Индивидуальный план

Приложение для iPhone (PWA): открыть документ Word (.docx), поправить в нём текст и сохранить снова в Word или в PDF.

- Меняется только текст. Шрифты, таблицы, поля и вид документа остаются как в исходном файле, поэтому сохранённый .docx печатается так же, как оригинал.
- Можно писать в любом месте: в тексте, в пустых клетках таблиц, вместо строк «____». Enter переносит строку.
- Документы и черновики хранятся только на телефоне (IndexedDB), в GitHub они не попадают. В списке есть «Сделать копию», «Переименовать» и «Удалить».
- Синхронизация (по желанию): документы хранятся ещё и в приватном репозитории GitHub. Новые и изменённые там документы появляются на телефоне сами, правки с телефона уходят туда. Включается строкой «Синхронизация» в списке документов: нужен ключ доступа GitHub (fine-grained token) с правом Contents: Read and write только на это хранилище.
- PDF собирается на телефоне: страницы раскладываются как в Word (разрывы между абзацами и строками таблиц) и сохраняются картинкой высокого качества (≈240 dpi). Для печати лучше всего подходит файл Word, он совпадает с оригиналом один в один.

## Установка на iPhone

Откройте сайт в Safari → «Поделиться» → «На экран Домой».

## Устройство

- `src/docx/document.ts`: открывает .docx, рисует каждый абзац (`w:p`) как редактируемый блок, а каждый кусок текста (`w:r`) как `<span>`. После правки `sync()` записывает текст обратно в те же `w:r`, сохраняя их форматирование. Картинки, поля, разрывы страниц и скрытый текст заблокированы и не меняются.
- `src/docx/props.ts`: стили, тема и форматирование Word. `src/docx/numbering.ts`: номера списков.
- `src/pdf.ts`: раскладка по страницам и PDF.
- `src/sync.ts`: синхронизация с приватным репозиторием через GitHub API.
- `src/main.ts`: интерфейс (список документов и редактор). `src/store.ts`: хранилище.

## Команды

```sh
npm ci
npm run dev       # локально
npm run build     # проверка типов и сборка
npm run deploy    # сборка и публикация в ветку main (GitHub Pages)
```
